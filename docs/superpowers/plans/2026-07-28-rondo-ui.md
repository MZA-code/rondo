# Rondo — Plan d'implémentation : interface et thèmes

> **Pour les agents :** SOUS-COMPÉTENCE REQUISE — utiliser `superpowers:subagent-driven-development`
> (recommandé) ou `superpowers:executing-plans` pour dérouler ce plan tâche par tâche.
> Les étapes utilisent la syntaxe case à cocher (`- [ ]`).

**Objectif :** l'interface complète du compteur — bibliothèque de widgets, trois archétypes
de mise en page, six thèmes graphiques, navigation aux boutons — développée et visible
**sur PC dans une fenêtre SDL**, sans aucun matériel.

**Architecture :** la logique d'affichage est séparée du dessin. Ce qu'il faut montrer
(valeur formatée, widget visible ou masqué, valeur périmée ou non) est calculé par des
fonctions pures testables unitairement ; LVGL ne fait qu'appliquer le résultat. C'est cette
séparation qui rend une interface graphique testable en intégration continue.

**Pile technique :** C++17, LVGL 9.2, SDL2, CMake, Catch2 v3.

## Contraintes globales

- **`ui/` ne lit que le bus de canaux.** Aucun thème, aucun widget ne connaît un
  fournisseur, une broche ou un capteur. C'est ce qui permet à un même thème de fonctionner
  sur une autre moto.
- **Règle d'affichage universelle, implémentée à un seul endroit :** un canal `Absent`
  masque le widget qui en dépend, un canal `Stale` l'affiche en opacité réduite. Aucune
  valeur périmée ne doit jamais être présentée comme à jour.
- **C++17**, `-Wall -Wextra -Wpedantic -Werror`, LVGL exclu de ces drapeaux (code tiers).
- **Aucune allocation dynamique dans la logique d'affichage pure** (`ui/format.*`,
  `ui/widget_state.*`, `ui/palette.*`) : ce code tourne sur la cible.
- **Résolution de travail 480 × 480, affichage circulaire.** Tout élément doit rester dans
  le disque inscrit : un texte qui déborde dans les coins est invisible sur la vraie dalle.
- Identifiants et messages de commit en **anglais**, commentaires et noms de tests en
  **français** (voir `rondo-core`).
- Le dépôt ne contient **aucune image** : les captures produites par le simulateur restent
  locales et ne sont pas commitées.
- **Prérequis :** le plan `rondo-core` est terminé. `ChannelBus`, `Reading`, `Validity`,
  `SimClock`, `Scenario` et `ScenarioPlayer` existent et leurs 39 tests passent.

    lv_display_t* display = lv_sdl_window_create(480, 480);

    while (true) {

        lv_delay_ms(idle_ms < 5 ? 5 : idle_ms);
    }
    return 0;
}

`ui/format.h` :

```cpp
#pragma once

#include <cstddef>

#include "core/channel_bus.h"

namespace rondo::ui {

// Taille de tampon suffisante pour toutes les fonctions ci-dessous.
inline constexpr size_t kFormatBufferSize = 16;

// Affiche a la place d'une valeur perimee ou indisponible. Jamais une
// valeur figee presentee comme a jour.
inline constexpr const char* kNoValue = "---";

// Ecrivent la valeur mise en forme dans `out`, toujours terminee par zero.
// Renvoient false et ecrivent kNoValue si la lecture n'est pas exploitable,
// ou une chaine vide si le tampon est trop petit.
bool formatSpeed(const Reading& r, char* out, size_t size);      // "68"
bool formatRpm(const Reading& r, char* out, size_t size);        // "4200"
bool formatTemp(const Reading& r, char* out, size_t size);       // "82"
bool formatOdometer(const Reading& r, char* out, size_t size);   // "002566"
bool formatTrip(const Reading& r, char* out, size_t size);       // "126.4"
bool formatVolts(const Reading& r, char* out, size_t size);      // "12.8"

}  // namespace rondo::ui
```

`ui/format.cpp` :

```cpp
#include "ui/format.h"

#include <cmath>
#include <cstdio>

namespace rondo::ui {
namespace {

// Facteur commun a toutes les fonctions : refuse un tampon trop petit,
// et remplace une lecture inexploitable par kNoValue.
bool prepare(const Reading& r, char* out, size_t size) {
    if (out == nullptr || size < kFormatBufferSize) {
        if (out != nullptr && size > 0) {
            out[0] = '\0';
        }
        return false;
    }
    if (!r.isUsable()) {
        std::snprintf(out, size, "%s", kNoValue);
        return false;
    }
    return true;
}

}  // namespace

bool formatSpeed(const Reading& r, char* out, size_t size) {
    if (!prepare(r, out, size)) {
        return false;
    }
    std::snprintf(out, size, "%d", static_cast<int>(std::lround(r.value)));
    return true;
}

bool formatRpm(const Reading& r, char* out, size_t size) {
    if (!prepare(r, out, size)) {
        return false;
    }
    std::snprintf(out, size, "%d", static_cast<int>(std::lround(r.value)));
    return true;
}

bool formatTemp(const Reading& r, char* out, size_t size) {
    if (!prepare(r, out, size)) {
        return false;
    }
    std::snprintf(out, size, "%d", static_cast<int>(std::lround(r.value)));
    return true;
}

bool formatOdometer(const Reading& r, char* out, size_t size) {
    if (!prepare(r, out, size)) {
        return false;
    }
    // Troncature et non arrondi : un odometre ne doit jamais afficher un
    // kilometre qui n'a pas ete parcouru.
    std::snprintf(out, size, "%06d", static_cast<int>(r.value));
    return true;
}

bool formatTrip(const Reading& r, char* out, size_t size) {
    if (!prepare(r, out, size)) {
        return false;
    }
    std::snprintf(out, size, "%.1f", static_cast<double>(r.value));
    return true;
}

bool formatVolts(const Reading& r, char* out, size_t size) {
    if (!prepare(r, out, size)) {
        return false;
    }
    std::snprintf(out, size, "%.1f", static_cast<double>(r.value));
    return true;
}

}  // namespace rondo::ui
```

`ui/widget_state.h` :

```cpp
#pragma once

#include <cstdint>

#include "core/channel_bus.h"

namespace rondo::ui {

enum class Presence : uint8_t { Hidden, Shown };

struct WidgetState {
    Presence presence = Presence::Hidden;
    bool stale = false;
    float value = 0.0f;
};

// Traduit une lecture du bus en decision d'affichage.
//
// C'est LE mecanisme qui rend un theme portable d'une moto a l'autre :
// un canal qu'aucun fournisseur n'alimente masque automatiquement le
// widget correspondant, sans que le theme ait a connaitre la moto.
WidgetState widgetStateFor(const Reading& r);

}  // namespace rondo::ui
```

`ui/widget_state.cpp` :

```cpp
#include "ui/widget_state.h"

namespace rondo::ui {

WidgetState widgetStateFor(const Reading& r) {
    switch (r.validity) {
        case Validity::Absent:
            return WidgetState{Presence::Hidden, false, 0.0f};
        case Validity::Stale:
            return WidgetState{Presence::Shown, true, r.value};
        case Validity::Fresh:
            return WidgetState{Presence::Shown, false, r.value};
    }
    return WidgetState{};
}

}  // namespace rondo::ui
```

## Tâche 3 : Palettes et contrôle de contraste

Un compteur de moto se lit en plein soleil, en mouvement, à travers une visière. Le
contraste n'est pas une préférence esthétique : c'est une contrainte de lisibilité, donc
elle est testée.

**Fichiers :**
- Créer : `ui/palette.h`, `ui/palette.cpp`, `tests/test_palette.cpp`
- Modifier : `ui/CMakeLists.txt`, `tests/CMakeLists.txt`

**Produit :**
- `struct Color { uint8_t r, g, b; }`
- `struct Palette { const char* name; Color background, primary, secondary, accent, warning, telltale_neutral, telltale_turn, telltale_beam; }`
- `float contrastRatio(Color a, Color b)` — norme WCAG, de 1,0 à 21,0
- `const Palette& paletteAt(size_t index)`, `size_t paletteCount()`

TEST_CASE("le contraste est symetrique") {
    const float ab = contrastRatio(Color{10, 20, 30}, Color{200, 210, 220});
    const float ba = contrastRatio(Color{200, 210, 220}, Color{10, 20, 30});
    REQUIRE_THAT(ab, WithinAbs(ba, 0.001f));
}

TEST_CASE("la couleur principale de chaque palette est lisible en plein soleil") {
    for (size_t i = 0; i < paletteCount(); ++i) {
        const Palette& p = paletteAt(i);
        INFO("palette : " << p.name);
        REQUIRE(contrastRatio(p.primary, p.background) >= 4.5f);
    }

    for (size_t i = 0; i < paletteCount(); ++i) {
        const Palette& p = paletteAt(i);
        INFO("palette : " << p.name);
        REQUIRE(contrastRatio(p.secondary, p.background) >= 3.0f);
        REQUIRE(contrastRatio(p.accent, p.background) >= 3.0f);
    }
}

TEST_CASE("les palettes ont des noms distincts") {
    std::set<std::string> names;
    for (size_t i = 0; i < paletteCount(); ++i) {
        names.insert(paletteAt(i).name);
    }
    REQUIRE(names.size() == paletteCount());
}

// Luminance relative d'une composante, selon la norme WCAG.
float channelLuminance(uint8_t v) {
    const float c = static_cast<float>(v) / 255.0f;
    return c <= 0.03928f ? c / 12.92f : std::pow((c + 0.055f) / 1.055f, 2.4f);
}

float relativeLuminance(Color c) {
    return 0.2126f * channelLuminance(c.r) + 0.7152f * channelLuminance(c.g) +
           0.0722f * channelLuminance(c.b);
}

float contrastRatio(Color a, Color b) {
    const float la = relativeLuminance(a);
    const float lb = relativeLuminance(b);
    const float lighter = la > lb ? la : lb;
    const float darker = la > lb ? lb : la;
    return (lighter + 0.05f) / (darker + 0.05f);
}

namespace rondo::ui {

void applyPresence(lv_obj_t* obj, const WidgetState& state) {
    if (obj == nullptr) {
        return;
    }
    if (state.presence == Presence::Hidden) {
        lv_obj_add_flag(obj, LV_OBJ_FLAG_HIDDEN);
        return;
    }
    lv_obj_remove_flag(obj, LV_OBJ_FLAG_HIDDEN);

`core/input/button_decoder.h` :

```cpp
#pragma once

#include <cstdint>

#include "core/clock.h"
#include "hal/i_digital_in.h"

namespace rondo {

enum class ButtonEvent : uint8_t { None, ShortPress, LongPress };

// Traduit l'etat d'un contact en appuis courts et longs.
//
// L'appui long est emis des que la duree est atteinte, sans attendre le
// relachement : en roulant avec des gants, un retour differe donne
// l'impression que le bouton ne repond pas.
class ButtonDecoder {
 public:
    ButtonDecoder(const IDigitalIn& pin, bool active_low, uint32_t long_press_ms);

    // A appeler regulierement. Renvoie au plus un evenement par appel.
    ButtonEvent poll(const IClock& clock);

 private:
    const IDigitalIn& pin_;
    bool active_low_;
    uint32_t long_press_ms_;

    bool was_pressed_ = false;
    uint32_t pressed_at_ms_ = 0;
    bool long_already_sent_ = false;
};

}  // namespace rondo
```

`core/input/button_decoder.cpp` :

```cpp
#include "core/input/button_decoder.h"

namespace rondo {

ButtonDecoder::ButtonDecoder(const IDigitalIn& pin, bool active_low, uint32_t long_press_ms)
    : pin_(pin), active_low_(active_low), long_press_ms_(long_press_ms) {}

ButtonEvent ButtonDecoder::poll(const IClock& clock) {
    const bool level = pin_.read();
    const bool pressed = active_low_ ? !level : level;
    const uint32_t now_ms = clock.nowMs();

    if (pressed && !was_pressed_) {
        was_pressed_ = true;
        pressed_at_ms_ = now_ms;
        long_already_sent_ = false;
        return ButtonEvent::None;
    }

    if (pressed && was_pressed_) {
        if (!long_already_sent_ && now_ms - pressed_at_ms_ > long_press_ms_) {
            long_already_sent_ = true;
            return ButtonEvent::LongPress;
        }
        return ButtonEvent::None;
    }

    if (!pressed && was_pressed_) {
        was_pressed_ = false;
        // Un appui long a deja produit son evenement : le relachement
        // ne doit pas en produire un second.
        return long_already_sent_ ? ButtonEvent::None : ButtonEvent::ShortPress;
    }

    return ButtonEvent::None;
}

}  // namespace rondo
```

#include "ui/navigation.h"

namespace rondo::ui {

Navigator::Navigator(size_t theme_count)
    : theme_count_(theme_count > 0 ? theme_count : 1) {}

void Navigator::onButtonA(ButtonEvent event) {
    switch (event) {
        case ButtonEvent::ShortPress: {
            const size_t next =
                (static_cast<size_t>(screen_) + 1) % static_cast<size_t>(Screen::Count);
            screen_ = static_cast<Screen>(next);
            break;
        }
        case ButtonEvent::LongPress:
            trip_reset_pending_ = true;
            break;
        case ButtonEvent::None:
            break;
    }
}

void Navigator::onButtonB(ButtonEvent event) {
    if (event == ButtonEvent::ShortPress) {
        theme_index_ = (theme_index_ + 1) % theme_count_;
    }
    // L'appui long sur B est reserve pour une evolution : ouverture du
    // portail de configuration WiFi (plan rondo-config).
}

bool Navigator::consumeTripReset() {
    const bool pending = trip_reset_pending_;
    trip_reset_pending_ = false;
    return pending;
}

}  // namespace rondo::ui

#include <fstream>

namespace rondo {

bool writePpm(const std::string& path, const uint8_t* rgb, uint32_t width, uint32_t height) {
    if (rgb == nullptr) {
        return false;
    }
    std::ofstream out(path, std::ios::binary);
    if (!out) {
        return false;
    }
    out << "P6\n" << width << ' ' << height << "\n255\n";

              static_cast<std::streamsize>(width) * height * 3);
    return out.good();
